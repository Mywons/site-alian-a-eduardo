Repositório e ramo

Como criar a chave de acesso
  1. Entre no GitHub e abra Settings → Developer settings → Personal access tokens → Fine-grained tokens.
  2. Toque em Generate new token. Dê um nome, como “Painel da loja”, e escolha a validade.
  3. Em Repository access, marque Only select repositories e escolha o repositório do site.
  4. Em Permissions → Repository permissions, coloque Contents em Read and write.
  5. Gere, copie e cole aqui. A chave fica só neste navegador.
